# Kasi Transport

Astro (static) + Tailwind v4 + Syne/Poppins. Content lives in `src/data/home.json`, edited through Pages CMS (`.pages.yml`).

- Dev: `npm run dev` · Build: `npm run build` (output `dist/`)
- Cloudflare Pages: build command `npm run build`, output directory `dist`, Node 20+
- Pages CMS: connect the GitHub repo at pagescms.org; images go in `public/images`
- All photos are placeholders in `public/images/*.svg` — replace with Kasi Transport photography.
